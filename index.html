Grok Bot

可以長期保留的 AI 隊友

Grok Bot 是可以長期保留的 AI 隊友（Bot／agent）：有名稱、有職責、有持續記憶。每隻 Bot 有自己一部雲端電腦（瀏覽器、檔案系統、終端機），可以在真實工具裏完成多步驟工作，而不是只產出對話草稿。

平台：桌面（macOS、Windows、Linux）及 iOS。

01

新手 5 步上手

以下按官方流程精簡，方便課堂逐步示範。

  1. 安裝 Grok Bot／Cursor 桌面 app（或於 iOS App Store 安裝）。
  2. 用同一個 Cursor 帳戶登入。沒有獨立的 Grok Bot 登入。
  3. 開第一隻 Bot：給一個短名稱、一個主要職責，以及它怎樣做。
  4. 用訊息交任務。說清楚結果、資料來源、完成標準、何時需要你批准。
  5. 服務需要登入時，Bot 會把電腦交還給你，由你自己登入。密碼不會給 Bot 看。
穩定之後 穩定的流程，可以請 Bot 跟隨你做一次，然後收成 skill 或 routine。

常見誤會

課堂可以先記一句：Cursor ≠ SuperGrok ≠ X Premium。

  1. Cursor ≠ SuperGrok ≠ X Premium 三條路都可以接觸到 Grok，但不是同一個計劃。Cursor 管編程，以及付費計劃內的 Grok Bot。SuperGrok 管 Grok 產品用量。X Premium+ 管 X 平台，並可連結 Bot。
  2. 連結 ≠ 變成 Cursor Pro 連結 SuperGrok 或 Premium+，得到的是 Grok Bot 用量授權，不會因此變成 Cursor Pro 或 Ultra。你買了 Cursor 哪一級，就仍然是那一級。舊日 Heavy 附送 Ultra 的促銷已經結束；已經領取的可能仍按 grandfather 安排保留，新的連結不再附送。
  3. Bot 額度不會疊加 Cursor 與 SuperGrok／Premium+ 不會 stack Bot 的每週額度。兩個都買，兩份費用都要支付，Grok Bot 額度不會加倍。每週額度用完後，可以用 Cursor 的 on-demand 另付費用繼續。
  4. SuperGrok 一般 ≠ X 平台特權 SuperGrok 購買的是 Grok／xAI 的 AI 能力（更高限額、Imagine／影片，部分級別有 Grok Bot）。它一般不包括 X 的藍剔、去除廣告、創作收入分成。X Premium+ 購買的是 X 平台，加上較強的 Grok，也可以連結開啟 Grok Bot。又要較高的 Grok 用量、又要 X 最高特權，通常要分開考慮（SuperGrok 加上 X，或只購買 Premium+，若你的需要只是「夠用的 Grok 加上 X」）。網上有文章指 Heavy 曾經或將會附帶 Premium+——以你帳戶的結帳頁，以及 xAI／X 條款為準。Cursor 文件沒有寫「SuperGrok 等於送上 X」。
  5. 連結是永久綁定 官方指出連結永久綁定，不能自行解除綁定並轉移帳戶。連結之前，先確認 Cursor 帳戶正確。

實務提醒

  1. 現時使用中的 Grok Bot，用量計在 Cursor 帳戶（每週額度，加上可選的 on-demand），不是「再買多一個就自動加倍」。
  2. 若已經有 Cursor Pro／Pro+／Ultra，通常不必再為了 Bot 去買 SuperGrok；除非你想要 grok.com 那邊的聊天與 Imagine 額度。
  3. 若只想要 Bot、不必寫程式：可以考慮 SuperGrok $30，或 X Premium+（若你本來就要用 X），然後再連結。連結永久綁定，不能自行解除綁定並轉移帳戶，連結前請確認 Cursor 帳戶正確。
  4. SpaceXAI／產品方曾公開表示會整合 Grok／Cursor 訂閱（約 2026-09 的消息，稱「數週內」），結構可能再變。訂立較長合約前，可再查看最新公告。

04

安全與登入

講解或示範之前，先說明這三點。

  • Bot 可以操作真實帳戶、檔案與網頁。只授權需要的範圍。
  • 不要把 API key 或密碼貼到 chat 或普通檔案。請使用秘密或安全的儲存方式。
  • 有些網站會阻擋自動化、工作階段（session）過期，或需要人手步驟（2FA／captcha）。這些時候，Bot 會交還給你。
登入 沒有獨立的 Grok Bot 登入，使用同一個 Cursor 帳戶。服務需要登入時，由你自己在交還的電腦上完成；密碼不會給 Bot 看。
